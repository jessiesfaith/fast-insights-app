# Financial Model — ML training kit

A hands-on kit for learning **SQL + Python + a first ML model** on one business
question: *a company has ~$10M to allocate — launch a **new product line**, make an
**acquisition (M&A)**, or **pay off debt**?*

The interactive walkthrough lives in the app at **https://app.fastinsights.io/financial-model**
(tabs for the big picture, SQL steps, Python & ML steps, the Power BI mock report,
the Excel report, and automation). This folder is the runnable half — do the steps
on your own machine as the app explains them.

## Get it onto your machine

Copy this whole `financial-model/` folder to **`C:\dev\Financial-Model`** (any
path works; that one matches the walkthrough). Then, one-time setup:

```bat
cd C:\dev\Financial-Model
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

You need: Python 3.10+ (python.org — check *Add python.exe to PATH* during
install), and optionally **DB Browser for SQLite** (sqlitebrowser.org, free) to
run the SQL files interactively yourself — strongly recommended for learning.

## The pipeline (matches the diagram in the app)

| Step | File | What it does |
|---|---|---|
| 0 | `data/generate_dataset.py` | Writes the certified historical CSVs (seeded — same data every run) |
| 1 | `python/00_load_database.py` | CSVs → `finmodel.db` (SQLite) + builds the feature views |
| — | `sql/01…04_*.sql` | The SQL you should read and run yourself in DB Browser |
| 2 | `python/01_explore.py` | Sanity-checks the training data (the pattern is visible by eye) |
| 3 | `python/02_train_model.py` | TRAIN → TEST → VALIDATE → APPROVE; writes `outputs/model_card_v1.json` |
| 4 | `python/03_inference.py` | Scores the 12 new companies → `outputs/prediction_table.csv` |

Run everything at once with `python run_pipeline.py` (or double-click
`run_pipeline.bat`), or run the steps one at a time — that is the learning path.

Expected results (fixed seed, so yours should match): 240 labeled companies,
test accuracy **88.3%**, validation gate **APPROVED**, 12 new companies scored.

## Outputs

- `outputs/model_card_v1.json` — the model's audit trail: metrics, the written
  validation gate, and the learned coefficients.
- `outputs/prediction_table.csv` — one row per new company with the probability
  of each action and the recommended move. This is the file Excel and Power BI
  import (the two report tabs in the app show exactly what to build from it).
- `finmodel.db` — the SQLite database (regenerated locally; not committed).

## Automate it (the "cron job")

The pipeline is scheduler-ready: `run_pipeline.py` exits non-zero on the first
failed step. On Windows, create a Task Scheduler task whose action runs
`run_pipeline.bat`; on Linux/Mac the cron line would be
`0 6 * * 1  cd /path/to/Financial-Model && python run_pipeline.py`. The app's
**Automate** tab walks through it — including what should *not* be automated:
re-approval of a retrained model is a human sign-off, not a scheduled job.

## Honest labels (read this once)

The data is **synthetic**, generated by `data/generate_dataset.py` with a fixed
seed so every learner sees identical numbers. The economics baked into it are
real (leverage → pay debt; hot market + margins → new product; cash + fragmented
market → M&A), but no real companies are involved and this is an education tool,
not investment advice.
